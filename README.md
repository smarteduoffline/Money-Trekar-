# হিসাবখাতা

অফলাইনে চলা ব্যক্তিগত ফিন্যান্স অ্যাপ (আয়-ব্যয়, ধার, আমানত, দোকান বাকি, বাজেট, রিমাইন্ডার)।
সব তথ্য আপনার ব্রাউজারের `localStorage`-এ থাকে — কোনো সার্ভার বা ইন্টারনেট লাগে না।

## চালানোর নিয়ম (GitHub Pages)
1. এই রিপোজিটোরির **Settings → Pages → Source** এ **GitHub Actions** বেছে নিন।
2. `main` ব্রাঞ্চে push করলেই অ্যাপ অটো ডিপ্লয় হবে।
3. লিংক: `https://<ইউজারনেম>.github.io/<রিপো-নাম>/`
4. একবার অনলাইনে খুললে পরে অফলাইনেও চলবে। ফোনে Chrome মেনু → **Add to Home screen**।

## ফাইল
| ফাইল | কাজ |
|---|---|
| `index.html` | পুরো অ্যাপ |
| `sw.js` | অফলাইন ক্যাশ (Service Worker) |
| `manifest.webmanifest` | ইনস্টলযোগ্য PWA সেটিংস |
| `icon-*.png` | অ্যাপ আইকন |
| `.github/workflows/pages.yml` | অটো ডিপ্লয় |

## সতর্কতা
ব্রাউজারের ডেটা মুছলে তথ্য চলে যায় — সেটিংস থেকে নিয়মিত JSON ব্যাকআপ নিন।
আপডেট দিলে `sw.js` এর `hisabkhata-v2` সংস্করণ নম্বর বাড়ান।
